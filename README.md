# Shuwaki Ibrahim

Personal portfolio and writing site for Shuwaki Ibrahim, pharmacist and software developer. The site highlights Shuwaki Worxpace, writing on pharmacy and software, and ways to get in touch.

## Local development

This is a static Jekyll site. To run it locally, install Ruby and Bundler, then:

```bash
bundle install
bundle exec jekyll serve
```

Open the local URL printed by Jekyll to view the site.

## Content

- `index.html` contains the portfolio and contact sections.
- `_posts/` contains blog posts written in Markdown.
- `_layouts/` contains the Jekyll page layouts.
- `assets/` contains images, styles, and client-side JavaScript.

## Contact form

The contact form opens the visitor's default mail app with a pre-addressed, pre-filled message to `shuwaki10@gmail.com`. Static GitHub Pages sites cannot deliver email themselves without a server-side or third-party form service.
